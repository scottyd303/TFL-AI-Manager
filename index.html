TFL AI Manager

Self-hosted fantasy football analytics and management platform

About

TFL AI Manager is a privately hosted fantasy football analytics application designed to help manage and analyze Yahoo Fantasy Football leagues.

The application runs locally using Docker and combines league data with analytics to provide roster evaluation, matchup analysis, waiver recommendations, and lineup decision support.

Features

  • Yahoo Fantasy Football league synchronization
  • Team and roster dashboards
  • Weekly matchup tracking
  • Standings and scoring analysis
  • Free-agent and waiver analysis
  • Player valuation and roster evaluation
  • Lineup recommendations
  • Fantasy football analytics and decision support

Yahoo Fantasy Sports Integration

TFL AI Manager uses the Yahoo Fantasy Sports API to retrieve authorized fantasy league information including league settings, teams, rosters, standings, matchups, scores, and player information.

Yahoo authentication is performed using OAuth. The current integration is read-only and is used for personal, non-commercial fantasy football analysis.

Privacy

TFL AI Manager is a personal, non-commercial project. Yahoo Fantasy Sports data is not sold, redistributed, or offered as a public data service.

Authentication credentials and access tokens are stored privately on the user's self-hosted server.
